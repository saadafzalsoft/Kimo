## 🚀 How to Host This Live on GitHub Pages (Free, Takes 2 Minutes)

You can share a live, working URL directly with your client by pushing this folder to GitHub:

### Option A: Via Git CLI (Recommended)
1. Open terminal inside this folder (`kino-live-preview`).
2. Create a new repository on your GitHub account (e.g., `kino-preview`).
3. Run the following commands:
```bash
git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/kino-preview.git
git branch -M main
git push -u origin main
```
4. On GitHub, go to your repository **Settings** → **Pages** (under "Code and automation").
5. Under **Branch**, select `main` and folder `/(root)`, then click **Save**.
6. GitHub will provide your live URL within ~30 seconds:
   `https://<YOUR-GITHUB-USERNAME>.github.io/kino-preview/`

---

### Option B: Via GitHub Web Upload (No Terminal Needed)
1. Go to [github.com/new](https://github.com/new) and name the repo `kino-preview` (Public).
2. Click **uploading an existing file**.
3. Drag and drop all files from this folder (`index.html`, `README.md`, and the `assets` folder).
4. Click **Commit changes**.
5. Go to **Settings** → **Pages** → choose `main` branch → **Save**.
6. Share the generated GitHub Pages link with your client!
